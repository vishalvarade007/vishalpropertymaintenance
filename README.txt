# Vishal Property Maintenance — One Page Website

## Files
- index.html — website structure/content
- style.css — design/responsive styling
- script.js — WhatsApp and phone settings
- logo.png — uploaded business logo

## Before publishing
Open `script.js` and replace:
VPM_PHONE = "91XXXXXXXXXX"
VPM_DISPLAY_PHONE = "+91 XXXXX XXXXX"

Example:
VPM_PHONE = "919876543210"
VPM_DISPLAY_PHONE = "+91 98765 43210"

Do not put spaces, +, brackets or dashes in VPM_PHONE.

## Free publishing
This site is a static HTML/CSS/JS website and can be published with GitHub Pages.
